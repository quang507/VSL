# Video mẫu cho từng từ (tuỳ chọn)

Đặt video minh hoạ ký hiệu vào đây, đặt tên **đúng bằng nhãn** + `.mp4`:

```
samples/Cứu.mp4
samples/Bệnh viện.mp4
samples/Ăn.mp4
```

Trang luyện tập sẽ tự hiển thị video mẫu nếu tìm thấy file tương ứng;
không có file thì khung video tự ẩn (không lỗi).

Gợi ý: có thể lấy 1 video đại diện cho mỗi nhãn từ dataset
ViSignLanguage-Video rồi copy vào đây.
